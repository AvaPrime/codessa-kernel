# AGK v1.0-rc1 — Layer A Contract Boundary\n\n## Frozen target\n\nThe implementation target is the five-stage deterministic pipeline:\n\n`NORMALIZE → CLASSIFY → VALIDATE → GATE → EMIT`\n\nThe model is an untrusted proposal generator. AGK is the deterministic governance boundary. AGK may emit READ, REASON, PREPARE, MUTATION_REQUEST, or BLOCK decisions according to the frozen policy. It never performs the external mutation itself.\n\n## Core rules\n\n1. Classified effect outranks declared effect.\n2. Applicable invariants cannot be bypassed by fast-path execution.\n3. BLOCKED is terminal for an immutable evaluation context.\n4. A changed evidence, authority, recovery, scope, target-state, input, or policy hash constitutes a new context.\n5. Verification for a mutation must be executable and bound to observable properties.\n6. Repetition of the same source is not independent corroboration.\n7. Model or text self-assertion does not create authority or canonical state.\n8. Layer A has no side effects.\n\n## Epistemic status\n\nThis repository establishes the executable implementation target. It does **not** itself establish AGK-M0 conformance. Conformance exists only after the generated receipt passes independent validation.\n\n## Undefined-contract handling\n\nThe supplied v1.0-rc1 working contract names twelve invariants but does not provide a complete machine-readable normative definition for every invariant in this repository. The implementation therefore uses only rules explicitly derivable from the frozen execution contract and marks any unresolved normative dependency as a harness/specification blocker rather than silently inventing authority.\n
